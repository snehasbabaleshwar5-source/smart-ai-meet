# Smart AI Meet

Smart AI Meet is an AI-powered virtual meeting platform that enhances security and user experience through biometric face verification, continuous face monitoring, and AI chatbot assistance. The system ensures that only authorized users can join meetings while providing real-time support and secure communication.

## Features
- Face Verification
- Real-Time Face Monitoring
- AI Chatbot Assistant
- Secure Meeting Management
- Video and Audio Communication

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- OpenCV
- WebRTC

## Purpose
To provide a secure, intelligent, and reliable online meeting platform for interviews, academic sessions, corporate meetings, and virtual conferences.
