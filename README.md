Smart AI – Face and ID Authentication System
Overview

Smart AI is an intelligent authentication system developed to provide secure and reliable user verification for online meetings and digital platforms. The system combines ID card verification and facial recognition technology to authenticate users before granting access. This approach helps prevent unauthorized entry, impersonation, and identity fraud while ensuring a seamless user experience.

Easy-to-Use Interface
How the System Works
The user uploads an ID card image in JPG or PNG format.
The system extracts and verifies the information from the ID card.
The user is prompted to capture a live facial image through the camera.
The facial recognition module compares the live face with the image present on the uploaded ID card.
If the facial features match, the user is authenticated and granted access.
If the verification fails, access is denied and the event is logged for security purposes.
